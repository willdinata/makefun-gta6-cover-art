VicePrint turns your photos into GTA-inspired game covers with four collage layouts, individually framed scenes, and editable display lettering. Mix Sunset or Neon grades with film grain and a vignette, then export a square, portrait, or landscape PNG at its exact post size. Anton and Bebas Neue are bundled locally with their Open Font License files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve the app/ folder with any static file server. Everything runs offline in the browser; photos never leave the machine.
